## Hello, I'm Dana 👋

I'm a full-stack developer and DevOps engineer from Kurdistan. I design and ship reliable products end to end—from database schemas and APIs to polished web and mobile interfaces, deployment pipelines, and self-hosted infrastructure.

My strongest work sits where **backend architecture**, **developer experience**, and **multilingual product design** meet. I care about secure defaults, clear documentation, observable systems, and software that feels natural in English, Arabic, and Sorani Kurdish.

## Currently building

- 📮 **TempMail** — a disposable-email SaaS with realtime inboxes, domain management, queue processing, and scalable message delivery.
- 🎛️ **CtrlApp** — a multi-platform control plane for managing applications, releases, configuration, and critical runtime controls.
- 🧠 **Kurdish AI tools** — NLP experiments for Kurdish question answering, sentiment analysis, text correction, and language accessibility.
- 🏠 **Self-hosted platform** — a practical homelab powered by Proxmox, Docker, private networking, secure tunnels, monitoring, and automated backups.
